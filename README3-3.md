## Функция first_vacant_row(seats)
1. УСЛОВИЕ ЗАДАЧИ
Цель функции: Найти первый ряд в зале, в котором имеется наибольшее количество свободных мест.
Входные данные:
•	seats — список списков, содержащий информацию о проданных билетах
o	1 — место продано
o	0 — место свободно
Выходные данные:
•	Кортеж (номер ряда, количество свободных мест)
•	Нумерация рядов начинается с 1
•	Если свободных мест нет вообще -> вернуть (0, 0)

2. АНАЛИЗ АЛГОРИТМА
Логика работы функции:
1.	Инициализировать переменные для отслеживания максимального количества свободных мест (max_count = 0) и номера ряда (max_row = 0)
2.	Пройтись по всем рядам с помощью enumerate()
3.	Для каждого ряда подсчитать количество нулей (свободных мест) через row.count(0)
4.	Если текущий ряд имеет больше свободных мест, чем предыдущий максимум -> обновить оба значения
5.	Вернуть номер ряда и количество мест

32	max_row = row_index	max_row = row_index + 1	Ошибка индексации

4. ПОДРОБНОЕ ОБЪЯСНЕНИЕ ОШИБОК
Ошибка 1 (строка 31): Неверное условие сравнения
Было: if available_seats_count >= max_count:
Стало: if available_seats_count > max_count:
Почему это ошибка:
Оператор >= (больше или равно) приводит к двум проблемам:
1.	Нарушается требование "первый ряд". Если есть несколько рядов с одинаковым максимальным количеством свободных мест, функция вернёт последний такой ряд, а не первый.
Пример: seats = [ [0, 0, 1], # ряд 1: 2 свободных [0, 0, 1], # ряд 2: 2 свободных (такой же) ]
o	С >= -> вернётся (2, 2) (неверно, последний)
o	С > -> вернётся (1, 2) (верно, первый)
2.	Некорректная обработка случая "нет свободных мест". При полностью заполненном зале (max_count останется 0) условие 0 >= 0 всё равно выполнится для последнего ряда, и функция вернёт его номер вместо 0.

Ошибка 2 (строка 32): Неверная нумерация рядов
Было: max_row = row_index
Стало: max_row = row_index + 1
Почему это ошибка:
Функция enumerate() возвращает индексы, начиная с 0, но по условию задачи нумерация рядов должна начинаться с 1.

•	Без +1 -> вернётся (0, 2) (неверно, нумерация с 0)
•	С +1 -> вернётся (1, 2) (верно, нумерация с 1)
