## Описание реализации  
Бинарный поиск (Binary Search) — алгоритм поиска элемента в отсортированном массиве.
Принцип работы:
1. Разделение пополам — на каждом шаге массив делится на две части
2. Сравнение с серединой — искомый элемент сравнивается со средним элементом
3. Отсечение половины — в зависимости от результата сравнения, одна половина отбрасывается
4. Повторение — процесс повторяется для оставшейся половины
### Характеристики:
**Сложность**: O(log n) — логарифмическая
**Память**: O(1) — константная (итеративная версия)
**Требовани**е: массив должен быть отсортирован по возрастанию
